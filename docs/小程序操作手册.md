# 小程序操作手册

> 面向两种人：**想跑起来的人**（第 1～2 节）和**想点着用的人**（第 3～7 节）。
> 接口契约见 [API.md](API.md)；本机后端已在 `127.0.0.1:3100` 运行。

---

## 0. 前置：后端必须先跑着

```bash
cd "E:\WorkflowGame\GetMoney\瑜伽卖课小程序"
node --no-warnings server/index.js      # 等价 npm start
```

自检：浏览器打开 <http://127.0.0.1:3100/api/_health>，看到 `"missing": []` 且 `modules.loaded` 有 10 项即可。

**手机真机调试**：需要后端监听局域网，而不是只听 127.0.0.1：

```bash
HOST=0.0.0.0 node --no-warnings server/index.js
```

- 手机用**同一个 WiFi**，访问 `http://<电脑局域网IP>:3100/api/_health` 能出 JSON 才算通。
  本机局域网 IP 是 **`192.168.1.3`**（另两个 `192.168.20.1` / `192.168.159.1` 是虚拟网卡，别用）。
- 当前这台机器上的后端**已经用 `HOST=0.0.0.0` 起好了**，`http://127.0.0.1:3100` 与
  `http://192.168.1.3:3100` 都返回 200，手机可直接连。
- Windows 防火墙若拦 3100：控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 勾 Node.js（专用网络）。

## 1. 打开小程序的三种方式

### 1.1 微信开发者工具（电脑模拟器，先用这个）

1. 下载安装「微信开发者工具」稳定版 Windows 64：
   <https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
   （本机**当前没装**，只有 QQ/QQ拼音等旧腾讯组件。）
2. 打开工具 → **导入项目** → 目录选：
   `E:\WorkflowGame\GetMoney\瑜伽卖课小程序\miniprogram`
3. AppID 处填 `touristappid`，或直接点「测试号」（工程里 `project.config.json` 已写 `touristappid`）。
4. 右上「详情 → 本地设置」勾选：
   **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**
   （`project.config.json` 里 `urlCheck: false` 已置，勾一次即可长期生效）
5. 点「编译」，模拟器出现标题为「瑜伽课堂」的首页，底部 4 个 tab：首页 / 课程 / AI 商城 / 我的。

> 工程是纯静态原生小程序（CommonJS + WXML），**不需要 npm 构建**，导入即可跑。

### 1.2 真机预览（手机微信扫一扫）

1. 后端按第 0 节用 `HOST=0.0.0.0` 启动。
2. 开发者工具点「预览」→ 生成二维码 → 手机微信扫码。
3. 手机进入小程序后，去 **我的 → 服务地址**，改成 `http://192.168.1.3:3100`
   （也可以在真机调试控制台执行 `wx.setStorageSync('mp_base_url', 'http://192.168.1.3:3100')`）。
4. 仍要勾「不校验合法域名」，否则真机会直接拦截 http 请求。
5. 用 `touristappid` 时真机预览有时长/次数限制，长期用请换自己的 AppID。

### 1.3 没有开发者工具时（等价验收通道）

H5 端与小程序**同一套接口、同一套字段**，流程完全一致：
<http://127.0.0.1:3100>（进 `#/login?demo=dev_demo_c` 这类链接可免输账号直接登录）。
后台：<http://127.0.0.1:3100/admin>。

## 2. 登录与切换演示身份

小程序是演示环境，不走微信授权，用内置演示账号：

**我的 → 设置 → 切换演示账号**，三选一：

| 账号 | 角色 | 分销位置 |
| --- | --- | --- |
| `dev_demo_a` | 馆主·林梵 | 一级（团队里有 B、C） |
| `dev_demo_b` | 学员·小满 | A 的下级 |
| `dev_demo_c` | 学员·阿橘 | B 的下级（C→B→A 两级链路） |

- Token 有效期 7 天，过期请求返回 401，重新切账号登录即可。

## 3. 学员动线：买课 → 上课 → 退款

```
首页 → 课程详情 → 确认订单 → 收银台 → 支付成功 → 我的课程（核销码）
                                                  ↘ 我的订单 → 申请退款
```

1. **首页**：顶部轮播、AI 顾问入口、「按目标选课」（减脂/塑形/孕产/理疗…）、热门课程双列卡。
2. **挑课**：点「按目标选课」的标签，或点任意课程卡 → 进入**课程详情**（价格、原价、折扣、老师、时长、排期、详情）。
3. **下单**：详情页选规格（如「陪练版」）→ 底部**立即购买** → **确认订单**（数量、备注）→ **提交订单**。
4. **支付**：进入**收银台**，显示订单号与金额。mock 模式下发起支付约 200ms 自动成功，页面 2 秒轮询会自己翻成「支付成功」；也可点「我已支付」立刻确认（幂等）。
5. **上课**：支付成功 → 「查看我的课程」→ **我的课程**列表 → 点开**课程详情**看 8 位**核销码**与上课须知（到店课出示核销码）。
6. **退款**：**我的订单** → 选中已支付订单 → **申请退款** → 选原因（课程内容与预期不符 / 时间冲突 / 买错课程）→ 金额**留空即全额**（可部分退）→ 提交。
   - 金额 ≤ 200 元且未核销：自动通过，原路退回；
   - 超额度或有核销记录：转后台审核；
   - 退款成功后订单变「已退款」，两级佣金自动冲正。

## 4. 分销员动线：开通 → 拉人 → 拿佣金 → 提现

1. **我的 → 分销中心**
2. 首次进入若显示「未开通」，点 **立即开通**。
3. **绑定上级**：分销中心底部输入邀请码（如 `DEMOA`）→ **绑定**。
   一次性操作，绑定后不可更改；系统防环（沿上级最多 32 层）。
4. **拉人**：**复制**邀请码 或 **分享给好友**（微信转发卡片）；对方在小程序里绑定你的邀请码即成为你的下级。
5. **佣金**：下级下单支付成功后生成——
   一级 15%（默认 `commission_l1_bps=1500`）、二级 5%（`500`），冻结 7 天后转「可提现」；退款自动冲正。
6. **提现**：切换 **提现** tab → 输入金额（默认最低 10 元）→ 提交 → 等后台审核打款。
7. **团队 / 佣金** tab：看两级成员、佣金明细（待结算 / 可提现 / 已冲正）、比例说明。

## 5. AI 商城：对话里完成买课与退款

入口：底部 **AI 商城** tab，或 **我的 → AI 顾问**。

| 你说 | AI 会给 |
| --- | --- |
| 「我想减脂」 | 商品卡 2 张 + 按钮「立即下单 / 看看详情 / 看看另一门」 |
| 「有没有入门课」 | 按目标选课 |
| 「多少钱」 | 价格说明 + 商品卡 |
| 「我的订单在哪」 | 订单摘要卡 + 「查看订单」 |
| 「我要退款」 | 退款卡 + 确认按钮（额度内直接通过） |
| 「怎么赚佣金」 | 分销规则 + 「去分销中心」 |
| 「找人工」 | 转客服，给「联系客服」按钮 |

- 点商品卡上的**立即下单**：直接在对话里建单，返回收银台卡（订单号 + 金额）；
- 点**去支付 / 模拟支付**：走 mock 支付，返回「已开通」卡（含核销码）；
- 说「退款」→ 对最近一笔可退订单发起退款，返回退款单号与状态。
- 资金类动作（下单/支付/退款）由后端规则引擎兜底，不会因为接了 LLM 而乱执行。

## 6. 客服

- **用户侧**：我的 → 在线客服（或 AI 里「联系人工」）→ 输入问题发送；顶部有未读红点；可结束会话再开新会话。
- **后台侧**：<http://127.0.0.1:3100/admin> → 客服 → 选左侧会话 → 右侧回复；可关单、看待办统计。
- 用户发消息后若无人值守，系统会先给一条 AI 自动回复，人工回复接在同一条会话里。

## 8. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 页面白屏 / 一直转圈 | 后端没起，或「我的 → 服务地址」指错端口 |
| 真机请求被拦 | 没勾「不校验合法域名」；或没把服务地址改成局域网 IP |
| 手机连不上电脑 | 后端没用 `HOST=0.0.0.0`；或防火墙挡了 3100 |
| 401 Unauthorized | token 过期（7 天）→ 我的 → 退出登录，重选账号 |
| 绑定邀请码报 409 | 已绑定过上级，不允许改绑 |
| 提现报 422/409 | 低于最低提现额（10 元）/ 可提现余额不足 |
| 退款按钮不可用 | 超 7 天窗口 / 课程已核销 / 已有在途退款 |
| 编译报 appid 错误 | 用「测试号」，或填自己的 AppID |
| 图片不显示 | 封面是后端生成的 SVG（`/api/media/cover/...`），检查服务地址是否可达 |
